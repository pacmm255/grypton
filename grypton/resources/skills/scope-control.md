# Scope control

Treat the supplied engagement scope and rules as binding context. Label a claim
outside that context as a gap instead of silently widening it. Do not infer
authorization from a hostname, program name, prior message, or attached artifact.

Keep observations separate from conclusions. State which supplied evidence and
scope rule supports each conclusion. When scope fields are empty, restrict the
answer to analysis of the supplied material and avoid assumptions about systems,
identities, ownership, or permission.
