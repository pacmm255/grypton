# Local requirements

The coordinator may arrange these capabilities without operator interaction:

- existing_evidence: re-use the already attached evidence snapshot;
- scratch_directory: use a private local directory allocated for this review;
- offline_email: return a reserved `.invalid` address, clearly marked synthetic,
  for reasoning about local fixtures; it is not an account or working mailbox.

external_account, missing_evidence, and network_access are unavailable. Record
the resource and its effect on certainty, and continue any independent checks.
Never create real accounts, obtain outside identities, change scope, purchase
services, or bypass access controls. Terminate a bounded review honestly when
the available evidence is exhausted.
